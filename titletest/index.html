ANIMA 2 — TITLE TREATMENT TEST

Four rarity treatments rendered through the real .title-badge contract — same 120×40 fixed size, same visibility:hidden name handling — so what you see here is what renders in the sidebar, chat, Switch Title dropdown and Showcase. The artwork below is placeholder art I drew, not sourced anime images; each one is a single background-image swap away from final. Judge the treatments, not the pictures.

COMMON

15% each · static image

Flat art behind a 3px white frame. No border colour, no glow, no motion — commons should read as "a picture in a frame" and nothing more, so the higher tiers have somewhere to go. Identical treatment to Anima 1's commons.

UNCOMMON

8% each · coloured border

Same flat art, but the frame takes a saturated per-title hue plus a 1px inner rim so the colour reads even against a bright image. Still no motion — the jump from common is purely chromatic, which keeps it legible at 12px in a chat line.

FrostlineFrostline · cyan
CinderstepCinderstep · ember
DuskweaverDuskweaver · violet

RARE

1.5% each · glow border

Coloured frame plus a slow pulsing halo that bleeds outside the chip — the first tier that draws the eye in a list of names. Uses box-shadow rather than a wrapper, so it costs no extra DOM and can't be clipped by the chip's own overflow:hidden.

Hollow CrownHollow Crown
VoidsongVoidsong
SunspearSunspear

MYTHIC

0.05% each · animated GIF bg

Live animated background plus a rotating conic aura ring. Because the chip itself is overflow:hidden, the aura lives on a thin wrapper around it (masked to a ring) — the same structural trick Anima 1's hyper tier uses.
